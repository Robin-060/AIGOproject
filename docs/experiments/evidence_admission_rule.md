# Evidence Admission Rule（证据准入制度）

> v1.5 冻结（2026-08-31）。本规则是 C 第四刀的落地：制度 > 代码。

## 规则原文

**任何候选证据，在进入 Reliability Engine 之前，必须证明两件事：**

1. **Error relevance（稳定的错误相关性）**：该信号与真实错误风险的关联，
   在自然数据（非注入数据）上可重复——用 DS4 式分析量化（分带错误率 + CI）
2. **Incremental value（增量价值）**：在已有证据之上提供额外区分能力——
   加入后排序质量（如 Equal-Coverage 点位的 Unsafe）经 validation 程序确认改善

## 执行程序（与现有纪律一致）

- 相关性分析只用 main 分片；增量价值按预注册准则（main 比较、holdout 确认）
- 未通过者不得进入引擎；通过者以版本化参数冻结

## 首例档案：STA/LTA 支持度证据（Rejected）

| 项 | 记录 |
|---|---|
| 候选 | STA/LTA 触发支持度（±W 窗口内有无触发） |
| Error relevance 测试 | 正确拾取 46.7% 无支持 vs 错误 60.9%——弱相关（DS4 式分析，n=708） |
| Incremental value 测试 | 12 组合（W×X）预注册校准，全部与基线持平（4.2%），X=0 胜出 |
| 裁决 | **Rejected**（2026-08-29），证据淘汰；STA/LTA 保留 Traditional 参照系用途 |
| 教训 | "机制不同"不等于"信息独立"——同一份波形的两个能量检测器共享盲区 |

## 后续候选评估顺序（供决赛窗口）

1. 各模型 Platt 校准置信度（✅ 已入引擎，v1.5）
2. 域熟悉度分数（ID-only gate，v1.5 修正 3——注意：它是**门控**不是**证据**，
   同样须按本规则证明相关性后才可作为风险输入）
3. 其他候选（振幅比、偏振、事件检测器一致性等）一律先过本规则
