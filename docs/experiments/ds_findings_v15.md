# DS 判定汇总（v1.5 新口径）

> C 口径调整（2026-08-31）：DS 不是"必须全绿的考试"，而是"系统能力的五个问题"。
> 如实报告成立、失败及边界；不追求 5/5。

## 五个问题与最终判定

| DS | 问题（新口径） | 判定 | 依据 |
|---|---|---|---|
| DS1 | Trust Layer 是否真的优于简单投票？ | ⚠️ **统计并列**（不强求） | 50% 点 Trust 5.5% vs Voting 4.6%，Δ=+0.9pp，95% CI [-1.4, +3.4] 含 0；优于其余 7/8 参照系。诚实边界：**同域、模型性能接近、样本简单时，复杂调度的边际收益有限**——这甚至回答了"什么时候不需要我们"，科研上是好事 |
| DS2 | 基础排序/规则是否可靠？ | ✅ **成立（保住）** | 风险分箱严格单调：3.96%→9.6%→28.57%（n=480/198/28） |
| DS3 | 分歧能否识别风险？ | 🔧 **逻辑已修正** | 实测不成立（P 不显著、S rho=0.09、完全一致带 11.3% 错误）→ v1.5 将分歧改为单向风险证据（SEVERE/MINOR/CONSENSUS 三级），FUSE 加校准置信度门槛 |
| DS4 | 数据质量是否真的预测错误？ | ❌ **不成立**（不强求） | 自然危害率仅为注入值 1/5-1/20。角色重定义：quality signal 是 **input integrity / hard-failure guard**，不是一般性错误概率代理；不人工调权重硬凑相关 |
| DS5 | distribution shift 能否被检测并触发降级？ | ✅ **成立（新标准）** | ID-only 域门：BLANCO 上 coverage 54.5%→19.5% 主动下降，retained unsafe 23.9%→21.8%。边界：retained 21.8% 仍高于域内 5.4%——门是必要护栏，非完整解药 |

## 附加发现（支撑判定）

1. 模型身份错位（geofon 指纹破案）→ model_registry 修正
2. "完全一致也会错"（DS3 副产品）→ FUSE 门槛的实证动机
3. OBSTransformer 置信度过度自信（0.9→实际 87%）→ 校准的直接对象
4. STA/LTA 弱相关（46.7% vs 60.9%）→ 首个被 Evidence Admission Rule 拒绝的候选
