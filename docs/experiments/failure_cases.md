# Trust Layer 失败案例分析

## 说明

SeisBench OBS 的 20 条正式噪声实验已经产生逐样本真实模型推理结果，但本轮 Trust Layer 没有放行任何错误 P/S 对，因此没有可诚实报告的 Trust Layer 真实“漏拦案例”。下列 8 个案例仍是按三种已知失效机制构造的分析模板，用于 Demo 演示、回归测试设计和后续更大样本替换，不应表述为本轮真实观察。

“没拦住”统一定义为：预测错误，但 Trust Layer 最终动作仍为 `ACCEPT`、`ROUTE` 或 `FUSE`，而非 `ABSTAIN`。

## 失败模式一：两个模型同时误拾

### 案例 C1-01：机械脉冲被一致识别为 P 波

- 输入：纯噪声窗口，在 18.2 s 出现短时机械脉冲。
- 模型输出：PhaseNet 18.20 s / 0.91，PickBlue 18.24 s / 0.88，OBSTransformer 无输出。
- Trust Layer 行为：两个可用模型的差值仅 0.04 s，形成共识并融合；系统没有事件存在性证据，错误被自动放行。
- 根因：共识只能证明模型彼此一致，不能证明它们与真实世界一致；两个模型可能共享训练偏差。
- 改进：加入第三个异构模型或独立事件检测器，并把“只有两个同源架构模型一致”标记为较高残余风险。

### 案例 C1-02：拖网噪声被一致识别为 S 波

- 输入：连续低频拖网噪声，26.0 s 附近出现能量上升。
- 模型输出：PickBlue 26.03 s / 0.87，OBSTransformer 26.17 s / 0.90，PhaseNet 因低置信度未形成有效候选。
- Trust Layer 行为：0.14 s 的 S 波时间差落在容差内，系统融合了两个错误拾取。
- 根因：两个 OBS 模型对同一种场景噪声具有相关误差。
- 改进：按模型家族而非模型数量计算投票权；相关架构的两个模型不应等价于两份独立证据。

### 案例 C1-03：共同预处理伪影

- 输入：重采样在 11.5 s 产生振铃。
- 模型输出：三模型都在 11.5 s 左右给出 P 波，置信度 0.82–0.94。
- Trust Layer 行为：三模型强共识，风险最低，错误融合。
- 根因：错误来自共享的上游预处理，增加模型数量无法消除共同原因失效。
- 改进：把预处理追踪和原始/处理后波形一致性作为独立证据；对同一预处理链的结果施加共同原因惩罚。

## 失败模式二：坏数据 + 高置信度

### 案例 C2-01：缺 H 通道但专用模型高置信

- 输入：仅 Z/N/E，H 通道缺失；适配器用零填充继续推理。
- 模型输出：PickBlue 给出 P=14.8 s / 0.93。
- Trust Layer 行为：如果 profile 或适配器错误地把输出标记为可比较，该高置信结果可能进入融合。
- 根因：置信度不等于输入适用性，且数据契约中的适配器状态可能不可信。
- 改进：数据质量硬门控必须早于模型分数；由平台根据实际通道计算可比性，不能只信任适配器自报。

### 案例 C2-02：大面积断点后的虚假边缘

- 输入：gap ratio 18%，补零边缘在 9.9 s 产生尖峰。
- 模型输出：PhaseNet P=9.91 s / 0.96，另一个模型 P=9.98 s / 0.89。
- Trust Layer 行为：共识和置信度都很强，当前数据风险预算不足以越过自动处理阈值。
- 根因：高置信度抵消不了结构性坏数据，但当前实现只累加固定数据惩罚。
- 改进：严重断点使用硬门控或动态降低自动处理阈值；风险组合应校准而非只靠手工相加。

### 案例 C2-03：削波导致相位形态丢失

- 输入：clipping ratio 22%，P/S 形态被削平。
- 模型输出：OBSTransformer 对错误 P/S 对仍给 0.92/0.90，时间顺序满足物理约束。
- Trust Layer 行为：物理检查通过，高置信结果被接受。
- 根因：当前物理证据只检查时间关系，不检查波形形态；数据惩罚没有直接否决严重削波。
- 改进：新增形态质量特征、严重削波硬阈值，并在校准集上评估覆盖率损失。

## 失败模式三：真值争议

### 案例 C3-01：低 SNR 弱 P 波

- 输入：SNR 约 1.5 dB，P 波起点在 21.4–22.0 s 间没有清晰边界。
- 模型输出：融合时间 21.72 s；标注员 A 标 21.45 s，标注员 B 标 21.91 s。
- Trust Layer 行为：若以 A 为唯一真值且容差 0.2 s，系统被判错；以 B 为真值则正确。
- 根因：二元正确/错误标签掩盖了标注不确定性。
- 改进：至少双人标注，保存标注区间和一致性；以软标签或时间区间计算指标。

### 案例 C3-02：重叠事件的 S 波归属争议

- 输入：两个相邻事件重叠，第一个事件的 S 波与第二个事件的 P 波接近。
- 模型输出：模型对拾取时间一致，但事件关联不同。
- Trust Layer 行为：仅按相位时间做共识，未发现关联错误，因此自动融合。
- 根因：当前 schema 缺少事件关联假设和多事件候选集合。
- 改进：引入 event association ID；金标准同时标注相位与事件归属。

## 后续真实案例替换清单

每个真实案例至少记录：`sample_id`、噪声等级、原始波形位置、人工标注及标注人、三模型 P/S 时间与置信度、四证据分解、最终动作、错误定义、根因和建议修复。替换构造案例后保留本页的失效模式分类，以便前后版本可比较。

本轮真实推理中可用于对照的基线错误包括：

- `XO.LA33..HH.2018.05.21.19.58.59` / L0：基线 S=46.09 s，标签 S=70.45 s。
- `XO.LT07..HH.2018.05.18.22.11.25` / L3：最高置信度 P=14.16 s，标签 P=44.99 s。
- `XO.LT04..HH.2018.05.25.08.40.15` / L1：基线 P=35.84 s，标签 P≈44.99 s。

这些错误均被 Trust Layer 拒绝，因此它们是“成功拦截案例”，不是 Trust Layer 失败案例。
