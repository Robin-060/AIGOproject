# Trust Layer 失败案例分析（真实数据版）

> 数据：SeisBench OBS 数据集 test split，895 条真实波形（官方 P/S 标注）
> 方法：Trust Layer（calibrated_v1.0 配置）逐条分析，找出放行但错误的样本
> 复现：`python -m src.experiments.real_baseline_final`

## 总体统计

| 指标 | 数值 |
|------|------|
| 总样本 | 895 |
| Trust Layer 放行 | 217 |
| 放行中正确 | 195 |
| **漏拦（放行但错误）** | **22** |
| 错误放行率 | 2.8% |

## 失败模式分布

| 模式 | 数量 | 占比 |
|------|------|------|
| 仅 S 波拾取错误 | 16 | 72.7% |
| 仅 P 波拾取错误 | 6 | 27.3% |
| P 和 S 同时错误 | 0 | 0% |

- P 波误差中位数：0.77s（容差 0.5s，仅轻微超限）
- S 波误差中位数：1.71s（容差 1.0s）

## 关键观察

### 1. 全部漏拦样本都是"多模型共识"

22 个漏拦样本中，**100% 是两个及以上模型给出相近拾取**。没有一个是单模型孤证被放行的——这符合设计：Trust Layer 只放行共识结果。

### 2. PhaseNet 在漏拦样本上几乎无检出

22 个漏拦样本中，PhaseNet 仅在 5 个上有任何检出（22.7%）。PhaseNet(geofon) 是陆地训练模型，在 OBS 数据上普遍失效——**实际参与共识的主要是 PickBlue 和 OBSTransformer 两个同域模型**。

### 3. S 波是主要薄弱环节

72.7% 的漏拦是 S 波错误。S 波起始点本就模糊（人工标注者间也存在分歧），且容差 1.0s 相对宽，模型在低信噪比下容易给出系统偏移。

## 典型漏拦案例

### 案例 1：两模型一致但 S 波晚了 47 秒（严重错误）

```
样本: XO.LD40..HH.2018.06.09.09.54.02
真值: P=44.99s, S=70.08s
TL 放行: P=45.05s, S=117.39s   ← S 晚了 47 秒!

PickBlue:       P=45.02, S=117.51 (0.77)
OBSTransformer: P=45.07, S=117.27 (0.87)

分析: 两模型都把 S 波拾到错误位置, 且高度一致 (差 0.24s)
      共识机制无法识别——它们共享同域训练偏差
```

### 案例 2：P 波轻微超限（边界错误）

```
样本: XO.LD38..HH.2018.06.17.04.31.57
真值: P=45.0s, S=61.96s
TL 放行: P=44.12s, S=62.10s

误差: P 波 0.88s (容差 0.5s, 超限 0.38s)
      三个模型都偏早: 44.01 / 44.12 / 44.19

分析: 系统性的提前拾取, 三模型方向一致
      不是随机噪声, 是共享的系统偏差
```

### 案例 3：S 波 1.7 秒偏差（典型）

```
样本: XO.LT04..HH.2018.06.20.21.38.21
真值: P=44.99s, S=55.57s
TL 放行: P=45.05s, S=57.28s

误差: S 波 1.71s
      两模型接近: 57.24 / 57.32

分析: 低信噪比下 S 波起始模糊, 模型拾到后续更强能量
```

## 根因总结

| 根因 | 表现 | 影响样本数 |
|------|------|------|
| 同域模型共享偏差 | 两模型一致但都错 | 22（全部） |
| S 波起始模糊 | 仅 S 错, 中位误差 1.71s | 16 |
| 系统性提前拾取 | P 波方向一致的偏差 | 6 |
| 相位误识别 | 拾到后续能量峰 | 部分 S 错误 |

## 与构造模板版的对比

早期失败案例（`failure_cases_template.md`）是按假设机制构造的 8 个模板。本次用 895 条真实标注数据实际跑出的 22 个漏拦样本，验证了模板中最重要的假设：

- ✅ "共识不能证明正确"（模板 C1 系列）——真实漏拦 100% 是共识样本
- ✅ "同域模型相关误差"（模板 C1-02）——PhaseNet 缺席, PickBlue+OBSTransformer 共享偏差
- ❌ "坏数据+高置信"（模板 C2）——真实漏拦中没有数据质量问题（批量数据全部干净）

## 改进方向

1. **加入第三个异构模型**：PhaseNet(geofon) 在 OBS 上失效，实际共识只有两个同域模型。引入不同架构/训练域的第三模型可打破共享偏差。
2. **S 波专项审查**：S 波贡献 73% 的漏拦，可考虑对 S 拾取单独设置更严的共识要求。
3. **模型家族去重**：PickBlue 基于 PhaseNet 底座，与 OBSTransformer 的独立性需在投票权重中体现——相关架构不应等价于独立证据。
