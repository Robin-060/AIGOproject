## 第 1 段：问题（0:00 - 0:30）

**屏幕**：黑底白字标题页（PPT 或图片）

```
OBS 可信AI调度层
Trust Layer for Ocean Bottom Seismometer

—— 当模型说"我不确定"
```

**口播**：

> "大家好，我们的项目是 OBS 可信 AI 调度层。
> 海底地震仪是深海科研的核心设备，深度学习已经能自动拾取地震波的 P/S 到时。
> 但有一个前提问题没人回答：模型这次的预测，可信吗？
> 我们在 895 条真实标注数据上实测，模型错误率高达 35.8%。
> 我们的系统要做的，就是在错误流入科研结论之前，把它拦下来。"

**要点**：
- 20 秒内说清"做什么"
- 35.8% 这个数字一定要说（真实数据背书）

## 第 2 段：Demo 演示（0:30 - 2:00）

### 场景 A：共识融合（0:30 - 1:10）

**屏幕操作**：
1. 打开 Demo（Streamlit 页面）
2. 点击"示例 1：三模型共识 → 融合"按钮
3. 鼠标依次指向：总览页 → 风险等级绿色徽标 → P/S 决策

**口播**：

> "打开我们的 Demo，点击示例一。
> 这是一条真实 OBS 波形，三个模型——PhaseNet、PickBlue、OBSTransformer——分别给出拾取结果。
> 看总览页：数据质量完好，三个模型高度一致，系统融合了两个模型的输出，风险等级 LOW，绿色徽标，自动放行。
> 再看风险分解：四类证据全部零分——系统能清楚地告诉你，它为什么信任这个结果。"

**要点**：
- 手指/鼠标跟着讲解走
- 强调"为什么信任"（可解释性）

### 场景 B：分歧拒绝（1:10 - 2:00）

**屏幕操作**：
1. 点击"示例 2：模型分歧 → 拒绝"按钮
2. 指向模型预测表：两个模型的 S 波时间差（24s vs 95s，差 50 秒）
3. 指向总览页：风险 MEDIUM 黄色徽标 → 决策 ABSTAIN

**口播**：

> "再看示例二，同样是真实数据。
> 注意两个模型的 S 波拾取：一个说 45 秒，一个说 95 秒，差了整整 50 秒。
> 传统做法是随便挑一个——比如分数高的那个——但这可能选错。
> 我们的系统做的是：承认自己判断不了，标记为'模型分歧待复核'，交给人工。
> 这就是核心创新：一个敢于说'我不确定'的 AI 系统。"

**要点**：
- 这是全场最重要的 50 秒，语速放慢
- "敢于说我不确定"是金句，务必说出来

## 第 3 段：实验证据（2:00 - 3:00）

**屏幕**：在 Demo 的"实验结果"标签页逐张滚动 5 张图

**口播**：

> "光说不行，我们用真实数据证明。
> 第一张，基线对比：在 895 条真实标注数据上，直接信单模型的错误放行率 29%，我们的系统降到 2.8%。
> 第二张，噪声鲁棒性：从干净到强噪声四档，我们始终保持零错误放行。
> 第三张，消融实验：多模型一致性证据是放行的核心通道。
> 第四张，置信度校准：模型说自己 90% 不代表真的 90%，我们做了校准。
> 第五张，风险校准曲线：风险分每升一档，实际错误率单调上升——证明评分体系本身是有效的。
> 更重要的：系统里每一个参数，都不是拍脑袋定的，全部经过真实数据校准。参数溯源表在仓库里完全公开。"

**要点**：
- 每张图一句话，不要念数字细节
- "参数都有数据背书"是第二个金句

## 录制清单

### 录前准备

- [ ] 项目目录干净，`git pull` 最新
- [ ] `python -m streamlit run src/web/app.py` 已启动且示例按钮可用
- [ ] 关闭所有无关窗口、通知
- [ ] 麦克风测试（说"测试"回听）
- [ ] 浏览器缩放 100%，隐藏书签栏

### 录中注意

- [ ] 鼠标移动放慢，点击前停半秒
- [ ] 每段之间留 1 秒静默（方便剪辑）
- [ ] 口播和操作同步，不要边想边说

### 录后检查

- [ ] 声音清晰无杂音
- [ ] 屏幕上文字可读（录屏分辨率 ≥1080p）
- [ ] 总时长 3-5 分钟
- [ ] 关键数字（35.8%、2.8%、50 秒）说对了

分两步：先录屏操作（不说话），再对着录屏配音（可用剪映/CapCut 的配音功能）。

录屏 + 文字标注（每段屏上打出核心数字），提交时说明。
