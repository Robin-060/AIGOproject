# 项目边界与数据合规说明

## 当前可验证范围

本仓库仅使用公开数据、公开预训练权重和本地生成的合成扰动，完成 OBS 波形预处理、震相拾取、多模型可信决策、传统基线、噪声鲁棒性评测和本地可视化演示。

当前结果属于公开数据上的工程原型验证，不代表特定海域、台阵、设备或科考任务的实际部署效果。

## 明确不在当前范围内的内容

1. 不采集、请求、处理或推断任何受限制、涉密或未获授权的南海 OBS 数据。
2. 不开展海上实地采集、科考现场部署、AUV/ROV 或水下硬件实验。
3. 因当前不具备真实用户实践条件，不宣称已经验证“降低 90% 人工工作量”。该目标保留为未来用户研究假设。
4. 不进行高精度三维地层反演或完整地震层析成像。
5. 当前事件分流是可解释规则，不冒充经过训练和独立验证的地震/噪声分类模型。
6. 当前模型未进行量化或剪枝；CPU 可运行结论来自本机公开数据工程测量。

## 对外陈述规则

- 可以陈述：在固定的 20 条 SeisBench OBS 公开测试波形上完成真实模型推理。
- 可以陈述：高噪声下 Trust Layer 未放行错误完整 P/S 对，但覆盖率为零。
- 可以陈述：模型和数据预先缓存后，分析流程可在本地 CPU 离线运行。
- 不得陈述：已在南海真实任务、海上科考或真实用户工作流中验证。
- 不得把安全拒绝率表述成震相准确率，也不得把构造失败案例表述成真实观测。
- 不得提交公开数据、模型或第三方代码前省略其原始来源、许可和引用要求。

## 后续验证条件

若未来具备合法授权数据和真实用户条件，应另行制定数据审批、脱敏、访问控制、人工金标准、用户知情同意和结果发布审查流程。未经授权，不把任何受限数据复制进本仓库或公共制品。
