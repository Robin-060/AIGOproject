## 你的模块 → M1

### `multi_model.py` — 多模型证据 (0-40 分)

输入 `List[ModelPrediction]` → 输出 `(score, reasons)`

```
1. 按 phase 分组: p_preds, s_preds
2. 统计模型总数 model_count
3. 对每组判断分歧程度
```

| 条件 | 加分 | 原因码 |
|------|------|--------|
| 全漏检 P | +15 | `MODEL_ALL_MISSING_P` |
| ≥2 模型 P 差 > 1.0s | +20 | `MODEL_DISAGREEMENT_P` |
| ≥2 模型 P 差 > 0.3s | +8 | `MODEL_MILD_DISAGREEMENT_P` |
| 全漏检 S | +15 | `MODEL_ALL_MISSING_S` |
| ≥2 模型 S 差 > 2.0s | +20 | `MODEL_DISAGREEMENT_S` |
| ≥2 模型 S 差 > 0.5s | +8 | `MODEL_MILD_DISAGREEMENT_S` |
| 有漏检但非全漏 | +10 | `MODEL_MISSING_PICK` |
| 全一致 | 0 | `MODEL_CONSENSUS` |

上限 `min(score, 40)`

# 一致 → 0, 严重分歧 → ≥20, 漏检 → ≥10
