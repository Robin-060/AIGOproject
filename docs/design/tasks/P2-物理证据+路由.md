## 你的模块 → M1

### 模块 1：`physics.py` — 物理证据 (0-15 分)

输入 `List[ModelPrediction]` → 输出 `(score, reasons)`

```
1. 取出 P 预测和 S 预测 (time_s > 0)
2. 如果 P 或 S 缺失 → (0, ["PHYSICS_INSUFFICIENT_DATA"])
3. 多模型取中位数 p_time, s_time
```

| 条件 | 加分 | 原因码 |
|------|------|--------|
| p_time >= s_time | +10 | `PHYSICS_P_AFTER_S` |
| S-P < 0.1s | +5 | `PHYSICS_SP_TOO_SHORT` |
| S-P > 60s | +5 | `PHYSICS_SP_TOO_LONG` |
| 全 OK | 0 | `PHYSICS_OK` |

上限 `min(score, 15)`

### 模块 2：`route()` — 写在 `reliability.py` 里

```python
def route(risk_score: float):
    if risk_score <= 30:   return ("LOW", "ACCEPT")
    elif risk_score <= 60:  return ("MEDIUM", "ROUTE")
    else:                   return ("HIGH", "ABSTAIN")
```
