## 你的模块 → M1

### 模块 1：`data_evidence.py` — 数据证据 (0-30 分)

输入 `QualityReport` → 输出 `(score, reasons)`

| 条件 | 加分 | 原因码 |
|------|------|--------|
| 缺 ≥2 通道 | +20 | `CHANNEL_MULTI_MISSING` |
| 缺 1 通道 | +12 | `CHANNEL_MISSING` |
| gap_ratio > 0.1 | +15 | `GAP_SEVERE` |
| gap_ratio > 0.02 | +8 | `GAP_MODERATE` |
| clipping_ratio > 0.1 | +10 | `CLIPPING_SEVERE` |
| clipping_ratio > 0.02 | +5 | `CLIPPING_MODERATE` |
| snr_db < 3.0 | +15 | `LOW_SIGNAL` |
| snr_db < 8.0 | +8 | `MODERATE_SIGNAL` |
| 采样率不匹配 | +5 | `SAMPLING_RATE_MISMATCH` |
| 全 OK | 0 | `DATA_QUALITY_OK` |

上限 `min(score, 30)`

### 模块 2：`single_model.py` — 单模型证据 (0-15 分)

输入 `List[ModelPrediction]` → 输出 `(score, reasons)`

| 条件 | 加分 | 原因码 |
|------|------|--------|
| 每个 score < 0.3 | +5 | `LOW_CONFIDENCE_{model}_{phase}` |
| 全部 ≥ 0.3 | 0 | `CONFIDENCE_OK` |

上限 `min(score, 15)`
