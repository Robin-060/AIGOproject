# 开源发布计划

## 发布内容

- Trust Engine、波形 I/O、预处理、STA/LTA 基线、Streamlit Demo 与评测脚本。
- README、实验报告、实验日志模板、数据与模型来源登记、项目边界与合规说明。
- 由脚本生成且可公开复现的汇总 CSV、JSON 和图表。

## 不随仓库发布

- SeisBench OBS 原始 HDF5/CSV 数据。
- SeisBench 或其他第三方预训练模型权重。
- 虚拟环境、缓存和临时文件。
- 任何受限、涉密、未获授权或可识别具体科考任务的数据。

## 发布前检查

1. 确认仓库顶层许可证与依赖许可证兼容性；当前仓库尚无顶层 `LICENSE`，正式公开前必须由项目负责人选择并确认。
2. 运行全部测试、Demo 健康检查和公开数据复现脚本。
3. 核对 README 命令、Python 版本、模型版本、文件哈希和图表数字。
4. 搜索密钥、个人路径、受限数据名称和大文件，确保不进入 Git 历史。
5. 按 SeisBench 官方引用指南列出软件、模型架构、预训练权重和数据集论文。
6. 给每次比赛提交打不可变版本标签，保留生成物与提交哈希对应关系。

## 维护约定

- 实验结论变更必须同时更新原始记录、汇总表、图、报告和 manifest。
- 模型或阈值升级必须新增版本，不覆盖旧实验语义。
- 外部贡献不得包含无明确授权的数据或权重。
- 安全处置率、覆盖率和准确率必须并列报告。
