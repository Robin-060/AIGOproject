## 1. 问题定义

### 1.1 我们解决什么问题

海底地震仪（Ocean Bottom Seismometer, OBS）是深海地球物理研究的核心观测设备，长期记录海底振动波形。从这些波形中自动识别地震并拾取 P/S 波到达时间，是深海地震学的第一步，也是后续震源定位、断层成像的基础。

深度学习已经能自动完成拾取：PhaseNet、PickBlue、OBSTransformer 等模型在标准数据集上表现出色。**但它们有一个共同的、未被解决的前提问题：模型的每次预测，可信吗？**

```
现有范式:                        我们的问题:
                                
波形 → 模型 → P/S 时间          波形 → 模型 → P/S 时间
        ↓                              ↓
      直接使用 ❌               "这次预测值得信吗？" ← 没人回答
```

### 1.2 为什么这个问题重要

模型在真实部署中的失败并非罕见，而是系统性存在：

| 失败模式 | 示例 | 后果 |
|------|------|------|
| **数据质量退化** | 通道缺失、仪器削波、强噪声 | 模型照常输出高置信结果 |
| **领域偏移** | 陆地训练的模型部署到新海域 | 论文性能无法迁移 |
| **模型间分歧** | 两个模型给出相差数秒的拾取 | 不知道该信谁 |
| **物理不可能** | P 波拾取晚于 S 波 | 物理上荒谬的结果进入下游 |

我们的实验（895 条真实标注样本）显示：**模型在 35.8% 的样本上存在拾取错误**。而现有工程实践是"信任一切模型输出"——错误直接流入地震目录，污染科研结论。

### 1.3 我们的问题陈述

> **在没有人工真值的情况下，如何评估多个拾取模型输出的可靠性，并据此决定自动接受、模型融合或人工复核——使错误拦截率达到最高，同时保持合理的自动覆盖率？**

这一问题的两个特性决定它不是简单阈值工程：

1. **多证据性**：可靠性取决于数据质量、模型自信度、模型间一致性、物理约束四类异构证据，单一证据不充分。
2. **可选择性**：系统必须允许"拒绝回答"（ABSTAIN），这是与传统"全自动流水线"的根本区别。

## 2. 我们的方案

### 2.1 系统架构

我们构建**模型无关的可信调度层**（Trust Layer），位于拾取模型之上、下游分析之下：

```
┌─────────────────────────────────────────────────────┐
│  数据层: PhaseNet / PickBlue / OBSTransformer       │
│          三模型推理 → 统一预测格式                     │
├─────────────────────────────────────────────────────┤
│  证据层 (Evidence Layer)                            │
│  ├─ 数据质量证据    数据本身可用吗？        (0-30)    │
│  ├─ 单模型证据      模型自己自信吗？        (0-24)    │
│  ├─ 多模型一致性    模型间一致吗？ ★核心    (0-37)    │
│  └─ 物理约束证据    物理上可能吗？          (0-40)    │
├─────────────────────────────────────────────────────┤
│  风险聚合 + 决策路由 (Reliability Engine + Router)   │
│  └─ 风险分 0-100 → ACCEPT / FUSE / ABSTAIN          │
├─────────────────────────────────────────────────────┤
│  输出: 风险等级 + 决策 + 完整原因链                    │
└─────────────────────────────────────────────────────┘
```

### 2.2 核心机制：证据融合与选择性决策

**四类证据**分别回答四个独立问题，加权求和为 0-100 的风险分：

```
风险分 = 数据证据(30) + 单模型证据(24) + 多模型一致性(37) + 物理约束(40)
```

**决策路由**按优先级执行六步：可比性检查 → 剔除硬失败模型 → 融合判断（两模型一致取中位数）→ 单模型选择 → 分歧时拒绝 → 默认拒绝。

关键设计：**证据不足时，系统说"我不确定"而不是猜一个答案。**

### 2.3 参数从何而来：全部数据驱动

所有阈值均经真实数据校准，而非经验拍定（详见参数溯源表）：

| 参数 | 校准方法 | 数据 |
|------|------|------|
| 一致性容差 P=0.34s / S=0.51s | 双模型正确时间差 95% 分位 | 真实标注 (n=674/455) |
| 证据权重 24/37/40 | 逻辑回归拟合 | n=895 |
| 物理边界 5.7-33.42s | S-P 时间差分布分位 | n=411 |
| 数据证据内部扣分 | 故障注入危害率反推 | 895×4 |

## 3. 实验验证

### 3.1 实验设置

- **数据**：SeisBench OBS 数据集 test split（公开、带官方人工标注），895 条真实波形；另含 4 档噪声版本（L0-L3）。
- **模型**：PhaseNet(geofon)、PickBlue(obs-phasenet)、OBSTransformer(obst2024)，全部为公开预训练权重。
- **评估**：P 波容差 0.5s、S 波容差 1.0s；错误 = 输出超出容差；拒绝 = 未输出完整 P/S 对。

### 3.2 核心结果：基线对比

| 方法 | 错误放行 | 说明 |
|------|------|------|
| 单模型（OBSTransformer） | 2/20 | 现有实践的默认做法 |
| 最高置信度选择 | 2/20 | 朴素多模型策略 |
| **Trust Layer** | **0/20** | **本系统** |

在 L0-L3 全部噪声水平下，Trust Layer 均保持零错误放行，而单模型基线每档泄漏 1-4 个错误。

### 3.3 消融实验：每个证据的贡献

```
关闭多模型证据: 正确通过 8 → 0 (全部拒绝)  ← 唯一的放行通道
关闭数据/单模型/物理: 无变化 (当前数据未触发)
```

多模型一致性是放行的决定性证据——这验证了设计的核心假设，也揭示了系统的保守性。

### 3.4 诚实报告：系统的代价与边界

系统是**安全优先的保守门控**：L0 拒绝率 60%，L1-L3 拒绝率 100%。我们将其明确报告为当前版本的特性而非缺陷：

> "当前版本优化错误拦截（100%），覆盖率作为明确的待改进项；风险阈值与证据权重的进一步校准需要更多样化的真实标注数据。"

### 4.3 团队

跨专业协作团队，成员背景涵盖计算机科学、信号处理、数据工程与可视化，按数据层、证据层、路由引擎、实验校准、前端 Demo 分工协作。全部代码公开，实验可复现。

- **科研**：为 OBS 地震 AI 提供首个可靠性评估基准，使"模型可不可信"可量化。

- **社区**：校准方法（差值统计、逻辑回归、故障注入）可复用于其他 AI-for-Science 项目。
